ChannelCleaner

Настройка собственного Telegram-бота для автоматического исключения подписчиков и отправки CSV. API ID и API Hash не нужны.

  1. Создай бота в @BotFather, скопируй токен.
  2. Нажми Start в личном чате с созданным ботом.
  3. Добавь этого бота администратором нужных каналов с правом блокировать участников.
  4. Если хочешь CSV в личные сообщения бота, узнай свой числовой Telegram ID через @userinfobot и нажми Start у своего бота.

Ключ хранится только в закрытом хранилище расширения на устройстве; на серверы разработчика данные не отправляются. Запросы на удаление идут напрямую в Bot API Telegram только после двух подтверждений конкретного канала и запуска кнопкой «Автоматически удалить». Бот проверяет членство перед исключением и после него. Ни пароли, ни коды входа в Telegram не нужны.

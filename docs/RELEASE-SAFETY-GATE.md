# Контроль допуска ChannelCleaner к работе на настоящем канале

**Это требования к допуску, а не свидетельство безопасного запуска.**

| ID | Проверка | Необходимое доказательство | Статус на момент добавления |
|---|---|---|---|
| CC-01 | Тестовый проход без удаления, результат CSV | мок + просмотр списка | NOT VERIFIED |
| CC-02 | Числовой ID и канал связаны однозначно | тест на подмену / несовпадение | NOT VERIFIED |
| CC-03 | Последовательные подтверждения оператора | UI-тест | NOT VERIFIED |
| CC-04 | Лимит удалений, стоп, повторный вызов | unit + integration | NOT VERIFIED |
| CC-05 | Журнал аудита и защита токена | security review | NOT VERIFIED |
| CC-06 | Проверка прав бота и API при отказах/429 | тестовый сценарий | NOT VERIFIED |
| CC-07 | Работа на актуальной разметке Telegram Web | ручная проверка на собственном тестовом канале | NOT VERIFIED |
| CC-08 | Не использовать Telegram Web online/status как точный срок отсутствия | объяснение ограничений пользователю | REVIEW |

Не выполнять CC-07 на реальных подписчиках. Отчёты и скриншоты — без имён, ID, токенов. Если проверка CC-02, CC-03, CC-04 или CC-07 не прошла, включение удаления должно считаться BLOCKED.

Перенесено из агентного аудита: риск-ориентированное QA, отдельный ревьюер, передача состояния, dry-run, минимальные полномочия и отсутствие «зелёной» отметки без запуска. Обратимость исключения из канала не гарантирована: прежняя подписка и контекст участия могут быть потеряны.

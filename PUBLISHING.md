# Публикация на GitHub

1. Откройте GitHub → New repository и создайте отдельный репозиторий, например `channel-cleaner`. Для передачи другим людям выберите Public.
2. Откройте страницу нового репозитория → **uploading an existing file** / **Add file → Upload files**.
3. Распакуйте ZIP и перетащите **содержимое** папки `ChannelCleaner_GitHub`, включая скрытые файлы `.gitignore` и `.github` (в некоторых интерфейсах скрытые файлы придётся добавлять отдельно).
4. Нажмите **Commit changes**.
5. Скопируйте ссылку на репозиторий. Эта публикация НЕ запускает бота и НЕ подтверждает работоспособность реального удаления.

**Не публикуйте** токен BotFather, файлы сессий, CSV подписчиков, списки реальных Telegram ID и скриншоты личных данных.

Исходники выложены без лицензии: это не означает предоставления сторонним лицам разрешения на распространение и изменение. Для открытой разработки следует отдельно выбрать подходящую лицензию.

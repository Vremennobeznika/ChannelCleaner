# ChannelCleaner 0.5 — собственная автоматическая очистка нескольких Telegram-каналов

**Что умеет:** после одного запуска самостоятельно проходит открытый список подписчиков Telegram Web, находит видимый статус «был(а) давно» / «last seen a long time ago», пытается получить **числовой ID** из той же строки и через собственного бота Telegram выполняет исключение участника. Для нескольких каналов есть отдельные профили, адреса, лимиты и отчёты. Токен только от BotFather, **без my.telegram.org, API ID, API Hash, Python, сервера или платного сервиса.**

**Ограничение приёмки:** алгоритм удаления реализован, но **не проверен на реальном Telegram Web и настоящем канале**. Это экспериментальная версия: подключение к реальному каналу и удаление даже одного тестового подписчика не подтверждены. До проверки использовать в тестовом канале. Вызов на реальном канале необратим для текущей подписки, хотя человек сможет подписаться снова.

## Запуск без программирования

1. Распакуй ZIP в постоянную папку.
2. На компьютере открой Яндекс Браузер (`browser://extensions`) или Chrome (`chrome://extensions`). Включи режим разработчика → **Загрузить распакованное расширение**, выбери папку с `manifest.json`.
3. Создай **собственного** бота через [@BotFather](https://t.me/BotFather), добавь его администратором каналов с правом **блокировать участников**. Открой настройки расширения и сохрани **токен бота** и свой числовой Telegram ID для необязательных отчётов. Не присылай токен другим людям.
4. В том же браузере открой [Telegram Web K](https://web.telegram.org/k/), войди в свой Telegram и открой **список подписчиков нужного канала**. Убери текст из поиска подписчиков.
5. В панели ChannelCleaner нажми **Добавить канал**. Можно создавать сколько угодно профилей в пределах лимита 100. У каждого свой `@username` публичного канала (или цифровой ID вида `-100...` для приватного), пауза, число прокруток и **лимит исключений за один запуск** (по умолчанию 10; допустимо 1–50). Нажми **Сохранить настройки канала**.
6. Отметь «Подтверждаю: открыт список подписчиков ВЫБРАННОГО канала».
7. Для безопасного знакомства сначала нажми **Пройти список**, затем **Скачать CSV**. Посмотри строку **«с ID»**. **Если 0, в этой версии реальная очистка невозможна**: Telegram Web не предоставил ID в видимой разметке.
8. Для реального исключения нажми **«Автоматически удалить»**. Подтверди предупреждение и отдельно — канал, который вернул Bot API. Расширение автоматически проходит список и исключает подходящих подписчиков **без клика по каждому**. **Остановить** прерывает дальнейшие действия после текущего запроса. Браузер нельзя закрывать.
9. Операции фиксируются в локальном журнале `channelCleanerV4:audit:<идентификатор профиля>`; удаление отражается в CSV. Поиск и чистка **не работают при закрытой вкладке**.

## Ограничения, которые нельзя скрывать

- Telegram официально определяет «был давно» как **более месяца**, но такой статус также показывается пользователю, **заблокировавшему наблюдателя**. Поэтому проверяется **не чтение канала**, и даже статус «был давно» не доказывает неактивность. Права на удаление и решение об использовании такого критерия остаются у владельца канала.
- Условие «человек не заходил именно в канал» **не определяется** этим методом.
- Обычный Bot API **не предоставляет последний вход**, его читаем из интерфейса Telegram Web. Если в конкретной версии страницы нет читаемого статуса либо числового ID в **той же однозначной строке**, человек **пропускается**, даже если его имя есть в CSV. Совпадающие имена не используются для удаления.
- Перед удалением бот проверяет канал и наличие административного права, проверяет, что пользователь — обычный участник, выполняет `unbanChatMember` (официально метод удаляет существующего участника без запрета последующего вступления) и перепроверяет отсутствие участника. На непроверенном ответе работа останавливается.
- Профили задаются отдельно. Канал из открытого окна и настроенный `@username` должны совпадать. Подтверждение требуется перед **каждым** запуском удаления.
- Нет круглосуточной безнадзорной очистки с закрытым браузером. Эта версия **автоматически выполняет серию исключений после одного запуска**, но требует открытой вкладки Telegram Web. Расширение не работает в отдельном приложении Telegram Desktop.
- Поддержка Яндекс Браузера Android теоретически возможна, **физический запуск Android не проверен**. На Windows Chromium тестирование ограничилось имитацией Telegram Web.
- Telegram может ограничить доступ к участникам, работу бота, запросы или изменить разметку. Расширение останавливается на ошибке, без небезопасных догадок.

## Статус публикации

**Экспериментальная версия.** Код и локальные mock-тесты доступны для проверки, но реальная установка в Telegram Web и удаление подписчиков не подтверждены. Не используйте автоматическое удаление на рабочих каналах до успешных испытаний на отдельном тестовом канале.

Это расширение, а не постоянно работающий серверный бот. Размещение на GitHub не включает автоматический запуск или хостинг. Настройки и токены **не должны** включаться в исходный код.

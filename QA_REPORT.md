# ChannelCleaner 0.5.0 — QA / 20 ноября 2026

## Приёмка

**Вердикт: НЕ ГОТОВО для автоматической очистки реальных каналов.** Реальная операция удаления и чтение фактического списка Telegram Web не испытаны. В коде реализован полный потенциальный сценарий автоматического удаления. Прошёл только тестирование на синтетической странице с имитацией Telegram Bot API.

**Внешний UX-тест с реальным человеком** не проводился. Применимость SEO, Core Web Vitals, GitHub Actions — **не применимо**: это локальное расширение, а не опубликованный сайт. Контейнер с Python/Node/Chromium не эквивалентен реальному Android и не проверяет безопасность Telegram-сессии.

**Риск:** статус `был давно` может означать блокировку администратора, а не реальное отсутствие более месяца. Порог по активности **именно в канале** недоступен. Справка Telegram: https://telegram.org/faq/ . Методы удаления: https://core.telegram.org/bots/api .
